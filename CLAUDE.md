# Claude Code compatibility

Use native project agents in `.claude/agents/` under the shared
[delegation policy](docs/agent-delegation.md). Read the relevant canonical
`.agents/skills/<name>/SKILL.md` when required; keep engineering rules there.
Choose a sufficiently capable included model and suitable effort explicitly at
invocation when supported. If selection is unavailable, do small tasks directly;
inherit only for a justified delegation under the policy. Keep project permission
controls and stop at allowance exhaustion; no paid fallback.
