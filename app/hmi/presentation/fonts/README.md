# HMI typeface

Both HMI presentations (the LVGL UI and the web demo) use **Tomorrow HMI**, our
modified version of Tomorrow by Tony de Marco and Monica Rizzolli, so they draw
the same glyphs. Product decision, 2026-10-03.

## Our modifications (the HMI cut)

Made by `tools/build_fonts.py --import-tomorrow`:

- **Equal-width digits.** Upstream digits are proportional (the 1 is about a
  third narrower than the 0), so changing readings would shift sideways. The
  digits are copied to new glyphs centred in the widest digit's advance; the
  copies carry no kerning.
- **Weights by role.** Body text uses Tomorrow **Medium**, strong text
  **SemiBold**. LVGL's unhinted 4 bpp rendering draws Tomorrow Regular too thin
  on the panel, so Regular is not used.
- **Subset** to ASCII plus ° · × – — … ‹ ›, kerning kept. Arrows (← →) are
  drawn as icons, and Tomorrow has no arrow glyphs.
- **Family renamed** "Tomorrow HMI" in the font name table.

## Layout

- `source/TomorrowHMI-Medium.ttf`, `source/TomorrowHMI-SemiBold.ttf`: the HMI
  cut. They are the only inputs; refresh them with `--import-tomorrow`.
- `OFL.txt`: the upstream copyright notice and licence.
- `generated/*.c`: LVGL fonts, 4 bpp, uncompressed, one per role and size
  (`furnace_hmi_font_regular_<size>` is body text, `..._semibold_<size>`
  strong text).
- `include/furnace_hmi/hmi_fonts.h`: `LV_FONT_DECLARE` for each generated font.
- The web demo embeds the same fonts as WOFF2 between its `hmi-fonts` markers
  (family `Tomorrow HMI`, body declared as weight 400, strong as 600).

Everything except `source/`, `OFL.txt` and this file is generated by
[`tools/build_fonts.py`](../../../../tools/build_fonts.py); do not edit it by hand.

## Weights and sizes

The web CSS uses weights 400, 500 and 600/700: 400/500 map to the body face
(Medium) and 600/700 to SemiBold. Sizes follow the web type scale; the list is
`FACES` in the generator. Grey (muted) text is at least 13 px in both
presentations. Add a size there, regenerate, and commit the new file.

## Commands

```powershell
# Upstream files: github.com/google/fonts/tree/main/ofl/tomorrow
# (Tomorrow-Medium.ttf, Tomorrow-SemiBold.ttf, OFL.txt in one folder)
.\.venv\Scripts\python.exe tools\build_fonts.py --import-tomorrow <folder>  # refresh sources
.\.venv\Scripts\python.exe tools\build_fonts.py                             # regenerate
.\.venv\Scripts\python.exe tools\build_fonts.py --check                     # fail if stale
```

The generator needs `fonttools` and `brotli` in the virtual environment and
Node.js (`npx lv_font_conv@1.5.2`). Building the firmware or UI lab does not.
