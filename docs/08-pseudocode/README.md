# Pseudocode policy

This directory is reserved for non-normative sketches that clarify a future
algorithm, lifecycle, or concurrency discussion before implementation.

Pseudocode must link to its governing requirements/ADR, label unresolved
behavior, and state that it is not the protocol schema or production logic. Do
not use it to bypass a decision record. Remove or update sketches when the
corresponding design changes so they cannot masquerade as current behavior.

No furnace or protocol pseudocode is needed during foundation setup.
